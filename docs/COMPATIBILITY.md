# Compatibility matrix (v0.1)

Legend: ✅ implemented · 🧪 implemented, **not yet verified on a real network by the maintainers** · 🗓 planned · ❌ not possible / not supported

All network paths in v0.1 are 🧪: the code exists and is unit-tested with fakes, but end-to-end connectivity has to be
confirmed through the [manual testing guide](TESTING.md). Mock Mode works everywhere the UI runs.

## Cloudflare WARP (research note)

WARP is WireGuard-based. Registration requires calling Cloudflare's undocumented client API (as done by community tools
such as wgcf / warp-plus), whose terms and stability are unclear. v0.1 therefore supports WARP only by importing a
WireGuard config produced by such a tool. Native registration is on the roadmap pending a license / ToS review.
