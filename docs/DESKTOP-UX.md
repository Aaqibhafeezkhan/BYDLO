# Интерфейс BYDLO

На главной состояние VPN и действие с ним видны сразу. Рядом с выбранным сервером показан охват подключения: прокси для настроенных приложений или всё устройство. Скорость и время появляются во время сеанса. Zapret и прокси Telegram находятся ниже: ими можно управлять независимо от VPN.

В разделе подключений серверы, цепочки и подписки разделены по задачам. Инструменты показывают отдельные настройки Zapret и Telegram. Маршрутизация и статистика доступны из боковой панели; в узком окне они открываются из настроек. Сохранение правил маршрутизации остаётся доступно при прокрутке.

Светлая тема использует чёрные основные кнопки на белом, чёрная — белые на чёрном. Серый отделяет области и второстепенный текст. Активное состояние, предупреждение и ошибка обозначаются текстом и значком. Для списков используются строки и разделители; отдельная поверхность выделяет задачу, например подключение или добавление сервера. Короткие переходы между страницами и при раскрытии секций отключаются настройкой «Уменьшить движение».

Для проверки компоновки и сценариев используйте Mock Mode. Скриншоты рендерятся из реальных представлений Avalonia без запуска VPN или вспомогательных сетевых инструментов:

```powershell
. ./scripts/env.ps1
dotnet run --project tools/Bydlo.Screenshots -c Release -- .tmp/desktop-review ru --mock --verify-overhaul
```
