# BYDLO v0.2.0

- Мастер добавления серверов показывает предварительный результат перед сохранением.
- Зашифрованная резервная копия переносит профили, подписки, ключи доступа и настройки.
- TgWsProxy встроен в BYDLO и работает без Python.
- Обновлены интерфейс рабочего стола и скриншоты в README.
- Архивы для Windows x64 и ARM64, Linux x64 и ARM64 и macOS ARM64 поставляются с контрольными суммами SHA-256.

## macOS: только Apple Silicon

Поддержка macOS на Intel прекращена. Новые релизы содержат только сборку `osx-arm64`
для Mac с Apple Silicon; сборки и обновления `osx-x64` больше не выпускаются.

Ранее опубликованные архивы для Intel не удаляются. Последнюю доступную сборку с
`osx-x64` следует искать в истории релизов; новые исправления в неё не переносятся.
