# BYDLO v0.4.2

- Проверка занятых портов учитывает активный туннель и владельца адаптера: профиль sing-box больше не блокируется соседним HTTP-портом, переключение с обычного TUN не скрывает занятый порт, а конфликт с TgWsProxy больше не приписывается нативным туннелям.
- TgWsProxy освобождает upstream при ошибке первой записи и при неудачной инициализации; защита Fake TLS отклоняет повторный ClientHello.
- Нативный WireGuard сохраняет возможность очистки после отмены запуска.
- Хранилище секретов отличает недоступный файл от отсутствующего, очищает временный plaintext при исключениях и отмене и проверяет обязательные ключи по протоколу; прокси без учётных данных по-прежнему принимаются.
- Экспорт резервной копии останавливается на нечитаемых обязательных секретах вместо молчаливого пропуска, а восстановление закрывается с ошибкой. Ошибка сохранения подписки больше не оставляет несохранённые изменения в памяти.
- Xray-core обновлён до 26.10.31; MPTCP в нём выключен по умолчанию.
- Релиз публикует один набор пакетов на платформу: девять пользовательских файлов, пять полных update `.nupkg`, пять RID feeds и `SHA256SUMS.txt`. Дублирующие ZIP каталогов и вторая семья AppImage больше не публикуются; прежние релизы и их URL остаются доступны.
- `SHA256SUMS.txt` пишется с LF и проверяется штатным `sha256sum -c`. Обязательный release gate не создаёт черновик при ошибке, отмене или неожиданном skip.

**Подпись Windows/macOS в этом выпуске временно пропущена.** BYDLO, его помощник и установщики не подписаны сертификатом издателя; macOS-пакеты не нотаризованы. Возможны предупреждения SmartScreen, UAC и Gatekeeper. SHA-256 и GitHub artifact attestations публикуются вместе с файлами; проверка происхождения описана в [BUILD.md](BUILD.md#проверка-происхождения-релиза). Постоянная подпись запланирована на 0.4.3 (#392).

Для обновления установите нативный пакет своей платформы из списка ниже и сохраните прежний каталог пользовательских данных. Старые ZIP каталогов автоматически не обновляются. Реальные подключения, установка и обновление на всех ОС не подтверждаются автоматическими mock-проверками; ограничения перечислены в [матрице совместимости](COMPATIBILITY.md).

Известные неблокирующие проблемы и дальнейшие улучшения перенесены в [milestone 0.4.3](https://github.com/endercodezz/BYDLO/milestone/7).

# BYDLO v0.4.0

- Профили Xray работают в режиме «Всё устройство» через TUN sing-box. Добавлен сбор статистики трафика через Xray StatsService. Для TLS в Xray поддерживается закрепление сертификата.
- Импорт подписок учитывает заголовки панели и позволяет настроить User-Agent для каждой подписки. Исправлен импорт отдельных конфигураций Shadowsocks и параметров транспорта Xray.
- В настройках можно скопировать диагностический отчёт с обезличенными настройками и очищенными от секретов логами.
- Исправлены обновление привилегированного помощника, восстановление сеансов и доступ к спискам Zapret после сброса привилегий на Linux. Обновлён встроенный список хостов Zapret для Windows.

Доступны архивы для Windows и Linux (x64 и ARM64) и macOS (Apple Silicon). Android остаётся в планах. Состояние ручных проверок и ограничения режимов приведены в [матрице совместимости](https://github.com/endercodezz/BYDLO/blob/main/docs/COMPATIBILITY.md).

Для обновления завершите работу BYDLO, скачайте ZIP для своей системы и сверьте его SHA-256 с `SHA256SUMS.txt`. Распакуйте весь архив в новую папку и запустите BYDLO из неё. Приложение загрузит настройки из прежнего каталога данных.

В Windows-сборках v0.4.0 исполняемые файлы BYDLO и его помощника поставляются без подписи. Контрольные суммы всех пяти архивов публикуются в `SHA256SUMS.txt`.

# BYDLO v0.3.1

Windows-сборки BYDLO в этом выпуске не подписаны. Контрольные суммы архивов доступны в `SHA256SUMS.txt`.

# BYDLO v0.3.0

## Что нового

- Переработан интерфейс рабочего стола: обновлены навигация, главный экран, подключения, инструменты и настройки. Скриншоты в README показывают новый интерфейс на русском языке.
- В галерее появилась тёмно-зелёная тема Forest со светлой листвой и розовыми акцентами. Её можно установить в настройках внешнего вида.
- Галерея показывает миниатюру, описание и автора темы. Палитра Ocean, тема релиза v0.2, обновлена.
- Мастер импорта принимает Clash/Mihomo YAML и поддерживаемое подмножество JSON-конфигураций sing-box и Xray. В каталоге публичных серверов можно выбрать отдельные узлы и проверить их задержку перед сохранением.
- Группы серверов sing-box и Xray поддерживают ручной выбор, выбор по задержке и переключение при сбое.
- В маршрутизации появились настройки DNS и собственные источники наборов правил с проверкой SHA-256. FakeIP доступен в режиме TUN sing-box.
- Системный прокси доступен в GNOME, KDE и macOS. В Linux и macOS можно включить ассоциации ссылок и файлов для импорта с предпросмотром. Статус ручных проверок указан в [матрице совместимости](COMPATIBILITY.md).

## Исправления

- Автообновление подписок сохраняет локальные настройки совпавших серверов и выбранные узлы. После ошибок повторные попытки выполняются с задержкой.
- При сбое движка без успешного переподключения BYDLO восстанавливает системный прокси. Перед запуском Xray проверяется также соседний HTTP-порт, а TUN sing-box на macOS использует автоматически назначенный интерфейс utun.
- Установка движков и запись локальных данных защищены от частичного обновления. Временные конфигурации с учётными данными удаляются после остановки и неудачного запуска.
- Исправлено переключение активного подключения из списка серверов. Отмена повышения прав сохраняет текущее подключение.

# BYDLO v0.2.0

Первый публичный релиз BYDLO на GitHub.

- Мастер добавления серверов показывает предварительный результат перед сохранением.
- Зашифрованная резервная копия переносит профили, подписки, ключи доступа и настройки.
- TgWsProxy встроен в BYDLO и работает без Python.
- Обновлены интерфейс рабочего стола и скриншоты в README.
- Архивы для Windows x64 и ARM64, Linux x64 и ARM64 и macOS ARM64 поставляются с контрольными суммами SHA-256.

## macOS: только Apple Silicon

Для macOS доступна сборка `osx-arm64` для Mac с Apple Silicon.
