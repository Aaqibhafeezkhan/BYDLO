# Редактирование профилей

На странице «Подключения» откройте меню профиля и выберите редактирование.
Можно изменить название, сервер, порт и движок. В разделе «Параметры протокола»
находятся SNI, транспорт, путь, fingerprint, Host, имя сервиса gRPC, ALPN,
Flow, параметры REALITY и шифр. Движки в списке поддерживают протокол на текущей ОС;
«Автоматически» оставляет выбор приложению. Установка движка и необходимые права
проверяются при подключении.

Для импортированной полной конфигурации OpenVPN, WireGuard, AmneziaWG, sing-box
или Xray сервер и параметры меняются в исходном тексте. После сохранения приложение
повторно разбирает конфигурацию и обновляет адрес профиля. Смена протокола требует
добавления нового профиля. Название, избранное и принадлежность подписке сохраняются.

Для OpenVPN с директивой `auth-user-pass` укажите логин и пароль в редакторе.
То же доступно через «Добавить сервер → Ввести вручную → OpenVPN»: вставьте
конфигурацию и заполните учётные данные. Переносы строк и пустые значения
не допускаются. Для конфигураций без `auth-user-pass` эти поля можно оставить пустыми.

UUID, пароли и исходные конфигурации скрыты до включения «Показать секретные поля».
Они сохраняются через защищённое хранилище секретов и не записываются в `profiles.json`.
Файл с логином и паролем OpenVPN создаётся только на время сеанса и удаляется при
остановке или ошибке запуска. Закрытие редактора без сохранения не меняет профиль.

В меню профиля также есть «Дублировать профиль» и удаление. Копия получает новый
идентификатор и независимые секреты. Активный профиль удалить нельзя.
