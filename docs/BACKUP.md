# Резервная копия и перенос настроек

В разделе «Настройки → Резервная копия и перенос» задайте пароль от 12 символов,
повторите его и нажмите «Экспорт копии». Сохраните файл `.bydlobackup` и пароль отдельно:
восстановить забытый пароль невозможно. Существующий файл заменяется только после
полной записи новой копии; удалённое хранилище без безопасной замены не перезаписывается —
выберите новое имя файла, чтобы прежняя копия сохранилась.

Копия содержит серверы вместе с ключами и исходными встроенными конфигурациями,
подписки вместе с секретными URL, ключ Telegram-прокси, настройки и правила маршрутизации.
Весь файл, включая названия серверов, зашифрован. Движки, логи, внешние файлы,
на которые ссылаются конфигурации OpenVPN, и пользовательские файлы списков Zapret
не переносятся. Локальные пути к движкам также не входят в копию.

Для импорта введите пароль в первое поле и нажмите «Открыть копию».
Повтор пароля нужен только при экспорте. Открытие файла показывает предпросмотр и ничего
не сохраняет. Он перечисляет названия записей и количество добавлений, перезаписей и удалений.

- **Объединение** выбрано по умолчанию. Записи с совпадающими ID перезаписываются,
  остальные серверы и подписки сохраняются. Одинаковые названия с разными ID считаются разными
  записями. Настройки берутся из копии, списки правил маршрутизации объединяются без дубликатов.
  Существующий ключ Telegram-прокси заменяется, если в копии есть ключ.
- **Замена** удаляет серверы и подписки, отсутствующие в копии, вместе с их ключами.
  Настройки, списки маршрутизации и ключ Telegram-прокси заменяются данными из копии.

Пути к движкам и Zapret, регистрация автозапуска, подключение при старте, завершённость
первой настройки и Mock Mode сохраняются от текущего устройства в обоих режимах.
Импорт не регистрирует системные службы и не меняет сетевую конфигурацию.
Настройки соединений вступят в силу при следующем подключении по вашей команде.

Перед применением остановите все подключения и инструменты BYDLO. Проверьте предпросмотр,
выберите режим и нажмите «Импортировать изменения». «Отменить предпросмотр» оставляет
текущие данные без изменений.

Формат версии 1 использует AES-256-GCM с тегом аутентификации 128 бит, случайной солью
128 бит и nonce 96 бит. Ключ выводится из пароля через PBKDF2-HMAC-SHA256 (600 000 итераций).
Неверный пароль и нарушение целостности отклоняются до применения данных.
Максимальный размер файла — 32 МиБ. Открытые секреты не записываются во временный файл:
в хранилище устройства они снова передаются через `ISecretStore`.
