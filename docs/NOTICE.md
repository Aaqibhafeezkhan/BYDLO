# Объявление проекта (`notice.json`)

Через файл `notice.json` в корне репозитория можно показать пользователям BYDLO плашку
без выпуска нового релиза. Например: «Не переживайте, скоро новый релиз с исправлениями».

Приложение читает файл из ветки по умолчанию:
`https://raw.githubusercontent.com/endercodezz/BYDLO/main/notice.json`.

- Запрос идёт при каждом запуске, если включена «Автоматически проверять новые версии».
  В Mock-режиме и с `BYDLO_SAFE_DEV=1` запросов нет.
- Без сети, при ошибке или при неверном файле плашки нет, запуск продолжается.
- Пользователь закрывает плашку кнопкой «Закрыть». Объявление с тем же `id` ему больше не
  показывается, а с новым `id` появится снова.
- Объявление видят только версии, в которых есть эта функция (начиная со следующего релиза
  после 0.2.0). Уже установленная 0.2.0 его не покажет.

## Формат

```json
{
  "id": "v0.3-soon",
  "level": "info",
  "title": { "en": "Fixes are on the way", "ru": "Исправления уже в пути" },
  "text": {
    "en": "Don't worry: most bugs are fixed, a new release is coming soon.",
    "ru": "Не переживайте: большинство багов исправлено, скоро новый релиз."
  },
  "url": "https://github.com/endercodezz/BYDLO/milestone/3",
  "hideFromVersion": "0.3.0",
  "expires": "2026-12-31"
}
```

| Поле | Обязательно | Значение |
|---|---|---|
| `id` | да | 1–64 символа: латиница, цифры, `.`, `_`, `-`. Пустой `id` — объявления нет. Меняйте `id` для каждого нового объявления. |
| `text` | да | Строка или объект «язык → текст» (`en`, `ru`). До 600 символов, длиннее обрезается. Если нужного языка нет, берётся английский. |
| `title` | нет | Заголовок, до 120 символов, в том же формате. |
| `level` | нет | `info` (по умолчанию) или `critical` (красная плашка). |
| `url` | нет | Кнопка «Подробнее». Допускаются только `https://github.com/endercodezz/BYDLO/...`, другие ссылки отбрасываются. |
| `hideFromVersion` | нет | Версия, начиная с которой плашка не показывается, например `0.3.0`. Неверная версия — объявление игнорируется целиком. |
| `expires` | нет | Дата или дата и время ISO 8601 (UTC по умолчанию), после которой плашка не показывается. |

Пустые строки считаются отсутствующими полями. Поэтому шаблон в репозитории, где все поля пустые,
означает «объявления нет».

Чтобы снять объявление, очистите `id` или верните шаблон. Изменения доходят до пользователей после
слияния в `main`, при следующем запуске приложения (с учётом кеша raw.githubusercontent.com,
обычно несколько минут).
