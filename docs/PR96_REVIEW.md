# Проверка PR #96

Дата: 3 ноября 2026 года. Проверен исходный коммит `6b1e7f9` и исправления
issue #99. Объём работы — уже написанный код PR; новые платформы и службы не добавлялись.

## Найденные и исправленные ошибки

- Явный выбор движка цепочки обходил новые ограничения готовых режимов маршрутизации
  и их сочетания с kill switch. Теперь используются те же проверки, что и при автовыборе.
- Импорт JSON принимал неверные типы секций, отсутствующие цели маршрутизации,
  несуществующие detour и участников selector/urltest. Эти случаи отклоняются до сохранения профиля.
- Восстановление резервной копии не проверяло новые коллекции и enum DNS, настройки DPI
  и упорядоченные правила. Повреждённые данные отклоняются; старые копии без новых полей принимаются.
- Ошибка первой остановки временного движка теста скорости оставляла процесс без повторной
  очистки. Добавлена повторная попытка через Dispose; при повторной ошибке сохраняются
  дескриптор и файлы для следующей очистки при остановке приложения. Учитываются общие настройки DPI.
- Кеш OpenVPN для macOS проверял только наличие файлов. Теперь проверяются сохранённые SHA-256
  и идентификатор, учитывающий SDK/toolchain, архитектуру, lock-файлы и скрипты сборки.
  После синхронизации с #102 устаревший идентификатор вызывает пересборку, а несовпадение
  сохранённого SHA-256 останавливает сборку. Без идентификатора кеш не используется.
- Снимки новых UI-проверок закрывало приветственное окно. Сценарии завершают приветствие,
  прокручивают до нужного элемента и снимают Purple, Light и OLED на широком и минимальном окне.
  Проверки выбора приложений Windows и активных соединений добавлены в CI.

## Отдельные исправления для основной ветки

Исправления #95 (изменяемая ссылка на секреты) и #97 (SOCKS-порт вместо HTTP-порта Xray)
выделены в отдельные ветки от актуальной основной ветки. Для обоих добавлены тесты,
воспроизводящие ошибку на исходном коде. Для #97 проверены обычный профиль и цепочка,
а также сохранение смешанного порта sing-box и очистка прокси при отключении.

## Проверки и ограничения

Исходный PR: Release без предупреждений, 440 изолированных тестов.
Исправленная ветка: Release с `-warnaserror`, 468 изолированных тестов.
Проверка исходных реализаций новыми регрессионными сценариями дала 20 падений;
после исправлений эти сценарии проходят. Кеш проверен отдельным PowerShell-сценарием
с фиктивными файлами: отсутствие, совпадение, изменение входов, повреждение файла,
неполный набор и некорректный manifest.

UI проверяется только через headless-инструмент с явным `--mock`; во всех проверках
включён `BYDLO_SAFE_DEV=1`. Реальные движки и сетевые настройки не затрагиваются.
Дополнительно выполнены headless-сценарии импорта, мастера добавления, тем,
резервных копий, передачи сервера, интеграции рабочего стола и встроенных движков.

## Синхронизация PR #101

Сохранены обе группы проверок CI: упаковка macOS/релизных архивов и новые UI-сценарии.

после восстановления повторяется проверка внешних зависимостей.

19 проверок упаковки/кеша, отдельные проверки идентификатора кеша, синтаксиса PowerShell и actionlint.

пройдены в Mock Mode. Полный macOS workflow для объединённой ветки повторно не запускался.
