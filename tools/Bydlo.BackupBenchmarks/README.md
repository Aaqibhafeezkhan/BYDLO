# Измерение импорта резервной копии

Только синтетические данные и локальное хранилище внутри `.tmp/`; сетевые движки не запускаются.
Из корня репозитория в PowerShell:

```powershell
. ./scripts/env.ps1
dotnet run --project tools/Bydlo.BackupBenchmarks -c Release -- 100 16384 5
```

Аргументы: число профилей, длина секрета каждого профиля в символах, число повторений.
Каждая фаза прогревается отдельно. `GC.GetTotalAllocatedBytes` измеряет суммарные выделения
управляемой памяти, включая продолжения асинхронного восстановления. Вывод — CSV.

Старый предпросмотр (`Decrypt` + `Preview`) сравнивается с открытием сессии и `Preview`;
обе фазы включают PBKDF2. Отдельно измеряются переключение режима без расшифровки,
повторная расшифровка без PBKDF2, восстановление заранее подготовленного `BackupData`
и применение с повторной расшифровкой. Запись файла и rollback-механизм входят в восстановление;
сбой записи здесь не моделируется. Это микробенчмарк, а не обещание ускорения интерфейса.

В предпросмотре сессия удерживает зашифрованную копию архива и производный ключ,
а также идентификаторы, имена и связи. Секретные строки подменяются очищаемым потоковым
разбором перед проверкой структуры; полные значения создаются только при применении.
Ключ, временный plaintext и рабочие символьные буферы очищаются явно.
Строки, созданные при применении, гарантированно стереть в управляемой памяти нельзя;
доступ к памяти процесса позволяет использовать сохранённый ключ для расшифровки.
После ошибки применения сессия закрывается; повтор требует открытия архива и ввода пароля.

Контрольный запуск 9 ноября 2026 года: Windows x64, .NET SDK 10.0.403, runtime 10.0.14,
Release, 100 профилей по 16 384 символа секрета, 5 повторений. Старый предпросмотр выделил
5 127 380 байт на операцию, сессия — 3 689 342 байта (примерно на 28% меньше).
Переключение режима — 10 608 байт, повторная расшифровка с материализацией — 5 093 777 байт,
восстановление готовых данных — 6 061 744 байта, применение с расшифровкой — 11 967 190 байт.
Среднее время фаз в том же порядке: 74,429; 68,926; 0,012; 1,152; 44,451; 51,319 мс.
Это один локальный запуск на синтетических данных; время зависит от машины, GC и диска,
а сокращение выделений на предпросмотре не означает сокращение стоимости применения.
