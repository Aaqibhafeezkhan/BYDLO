# Third-party notices

BYDLO is licensed under GPL-3.0-or-later. It builds on the work of many projects. Network engines are **separate
programs**: BYDLO launches them as external processes and does not link to them. When BYDLO downloads an engine, it
fetches the official upstream release asset pinned in [`engines/engines.lock.json`](engines/engines.lock.json) and
verifies its SHA-256. Source code of each engine is available from its upstream repository listed below.
